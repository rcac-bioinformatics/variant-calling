## variant-calling

A hands-on workshop on calling germline SNVs and small indels from Illumina short-read data on Purdue RCAC clusters. Learners work with the Genome in a Bottle Ashkenazi trio (HG002, HG003, HG004) on GRCh38, from raw reads through alignment, joint calling with bcftools, filtering and benchmarking, annotation, and a trio analysis.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/) and is in development (pre-alpha).

- Lesson site: <https://rcac-bioinformatics.github.io/variant-calling>
- Build locally: `sandpaper::build_lesson()` or `sandpaper::serve()` from the repository root in R.
